# Stock-price-forecasting-using-Python-LSTM-and-DeepAR.
This project implements two time-series forecasting models—Stacked LSTM (TensorFlow/Keras) and DeepAR (PyTorch/GluonTS)—to predict the short-term stock price of Cipla Ltd. Historical stock data from Yahoo Finance (2018–2026) is used to generate 7-day forecasts and compare model performance using RMSE, MAE, MAPE, and R².
